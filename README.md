## Running the Project

```bash
# psql setup: create a .env file at root direc.
DSN=
sslmode=
DB_USER=
DB_PASSWORD=
DB_NAME=
DB_HOST=
DB_PORT=


# with docker.
docker build -t second-life .
docker run -p 8080:8080 second-life
```
